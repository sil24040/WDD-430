# Crystal Clear

A Node.js + Express rental listing application with landlord and renter workflows.

## Features
- User registration and login
- Role-based landlord / renter access
- Room browsing and contact workflow
- Landlord room create / update / delete
- Landlord message inbox for renter contacts
- Persistent JSON-backed sample data

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the server:
   ```bash
   npm start
   ```
3. Open the app in your browser:
   ```
   http://localhost:4000
   ```

## Tests

Run the automated test suite:

```bash
npm test
```
